# Why the recall desk has no front end

A coordinator asks which vehicles need contact, where a dealer handoff is stuck and which remedy evidence awaits review. The CLI answers from the database. npm run view renders three branded, read-only snapshots; npm run docs renders progress, handoff and evidence worksheets.

A screen offers live multi-user work, mobile capture, offline photos, customer self-service, authentication and drag-and-drop scheduling. This free version provides none of those. Snapshots are private files and are current only when regenerated. Evidence references point to documents held elsewhere.

The database is the product. Claude Code, Codex, OpenCode or Cursor is a way to ask for work. A competent coordinator can operate the desk without a web application. If your business needs connected screens, Enterprise DNA scopes and builds them with the access controls and integrations your operation requires.

Safety decisions, repair instructions and regulatory submission remain in the supplier's approved processes. The free version is not a full replacement for Automotive Cloud, a workshop system or a recall authority.
