# Add a view

Read CLAUDE.md, views.json and the schema. Ask what question the operator wants to answer if it is unclear. Write a SELECT using existing records, validate totals against the CLI, then add a named entry to views.json. The renderer runs in a read-only transaction. Run npm run view and inspect the result. Do not add forms, sends, public hosting or a write endpoint.
